# Guitar Hero PC Tweaks - Now with GHWT:VR!

Fixes and improvements for the PC versions of Guitar Hero III and Guitar Hero World Tour.

Each tweak lives in its own folder with its own README and can be combined arbitrarily.

| Tweak | Games | What it does | Requires |
|---|---|---|---|
| [Rock Band guitar fix](gh3-rb-fix/) | GH3 | Makes Xbox 360 Rock Band guitars (e.g. the RB1 Stratocaster) play correctly | |
| [DxWnd configs](dxwnd/) | GH3, GHWT | Borderless window at native resolution, uncapped FPS, much lower input lag | |
| [4GB](4gb/) | GHWT | 32 bit executables are limited by default to 2GB. This script sets the Large Address Aware flag to let it have up to 4GB of address space. | |
| [Any mic](wt-any-mic/) | GHWT | Use any microphone for vocals (whatever is your Windows default recording device), no renaming needed | |
| [WT:VR](wt-vr/) | GHWT | Play in VR with any OpenXR headset: head-tracked stereo on stage with the band, the highway floating in front of you, and 3D notes | [4GB](4gb/) |

## Downloads

Ready-to-use files are on the [Releases](../../releases) page. The folders here hold the source and configs.

## Compatibility

All tweaks are tested together. The Rock Band guitar fix works under DxWnd and when launched through Steam (including non-Steam shortcuts with the overlay on).
